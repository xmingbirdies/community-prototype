# 18Birdies Community · Phase 1 prototype

Clickable PWA prototype: Friends feed, Interests, swipe Discover with video, following controls, and events in Play.
Sample people, photos and videos are placeholders.

Install on a phone: open the GitHub Pages link, then
- iPhone (Safari): Share > Add to Home Screen
- Android (Chrome): menu > Install app

After changing files, bump `VERSION` in `sw.js` so installed copies update.
